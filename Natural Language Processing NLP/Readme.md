# Assignment 1 - Financial News Syntactic Analysis

## Overview

This assignment applies Natural Language Processing techniques to a **financial news dataset** to explore and analyze textual and syntactic information.

The work includes text preprocessing, exploratory analysis, Part-of-Speech tagging, dependency parsing, constituency parsing, and comparison of parsing approaches.

## NLP Tasks Performed

### 1. Text Preprocessing and Exploration
- Financial news text analysis
- Text cleaning and preprocessing
- Exploratory analysis of textual data

### 2. Part-of-Speech (POS) Tagging
POS tagging is applied to identify the grammatical roles of words in financial news sentences.

### 3. Dependency Parsing
Dependency parsing is performed using **spaCy** to analyze grammatical relationships between words.

### 4. Constituency Parsing
Constituency parsing is performed using **Benepar** to analyze the hierarchical phrase structure of sentences.

### 5. Parser Comparison
The dependency and constituency parsing approaches are compared based on their processing and efficiency.
