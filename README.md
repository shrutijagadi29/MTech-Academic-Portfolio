# M.Tech Artificial Intelligence & Machine Learning Portfolio

This repository contains selected academic projects and assignments completed during my **M.Tech in Artificial Intelligence and Machine Learning at BITS Pilani**.

The portfolio covers practical implementations across Machine Learning, Artificial Intelligence, Deep Learning, Reinforcement Learning, Natural Language Processing, Advanced Deep Learning, and Computer Vision.

The projects include applications of classical machine learning, neural networks, generative models, reinforcement learning, NLP, computer vision, satellite imagery, and multimodal learning.

### 8. Computer Vision

Worked on traditional computer vision, machine-learning-based image classification, satellite imagery, remote sensing, and multimodal deep learning.

#### EuroSAT Satellite Image Classification

Developed an **Urban vs Natural satellite-image classifier** using handcrafted visual features and machine-learning models.

**Techniques:**
- Image preprocessing
- Local Binary Pattern (LBP)
- Histogram of Oriented Gradients (HOG)
- Image histograms
- PCA
- Support Vector Machine
- Random Forest

**Results:**
- SVM Accuracy: **98.6%**
- Random Forest Accuracy: **94.8%**

**Dataset:** EuroSAT

#### Cross-Modal NO₂ Prediction

Explored NO₂ prediction using satellite observations combined with environmental and contextual information.

**Key areas:**
- Sentinel-5P / TROPOMI data
- Satellite data preprocessing
- QA and cloud filtering
- CNN feature extraction
- Meteorological features
- Population and temporal features
- Multimodal learning
- Cross-modal feature fusion
- Transformer Encoder

**Tools:** Python, OpenCV, Scikit-image, Scikit-learn, PyTorch, Xarray, NumPy, Pandas
