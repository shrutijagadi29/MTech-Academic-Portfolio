# Artificial Intelligence and Computation (ACI)

This folder contains coursework and assignments completed as part of the **Artificial Intelligence and Computation** subject in my M.Tech program.

## Assignments

### 1. Relief Supply Intelligent Agent

Development of an intelligent agent for relief supply delivery using AI search and optimization techniques.

**Key concepts:**

* PEAS framework
* Random Restart Hill Climbing
* A* Search Algorithm
* Heuristic and fitness functions
* Graph-based path finding
* Time and space complexity analysis
