# Assignment 2 - AI Game and Expert System

## Overview

This assignment explores Artificial and Computational Intelligence concepts through two implementations.

## Part 1: Three-Player Tic-Tac-Toe

Implementation of a **3-player Tic-Tac-Toe game on a 9×9 board**.

**Key concepts:**

* Minimax Algorithm
* Alpha-Beta Pruning
* Static Evaluation Function
* AI-based move selection
* Prolog-based decision rules
* Interactive Expert System

## Part 2: Graduate Admission Prediction

Development of a **Graduate Admission Prediction System** using academic and profile-related attributes.

**Key concepts:**

* Decision Tree Classifier
* Data preprocessing
* Feature selection
* Decision rule extraction
* Prolog Knowledge Base
* Interactive admission prediction

The Decision Tree model achieved **81% accuracy** in the submitted implementation.

## Technologies Used

* Python
* Scikit-learn
* Prolog
* Jupyter Notebook
