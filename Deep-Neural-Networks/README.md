# Deep Neural Networks (DNN)

This folder contains coursework and assignments completed as part of the **Deep Neural Networks** subject in my M.Tech program.

## Assignments

### 1. IMDB Sentiment Classification using DNN

Implementation of a **Deep Neural Network** for binary sentiment classification of IMDB movie reviews.

**Key concepts:**

* Deep Neural Networks
* Dense layers
* ReLU and Sigmoid activation
* Dropout regularization
* Binary classification
* Early stopping
* Model evaluation

📁 **Assignment:** [IMDB Sentiment Classification using DNN](./Assignment-01-IMDB-Sentiment-DNN/)

### 2. Pneumonia Detection using CNN-Transformer

Literature exploration and implementation of a **Hybrid CNN-Transformer architecture** for pneumonia detection from chest X-ray images.

**Key concepts:**

* Convolutional Neural Networks (CNN)
* Transformer architecture
* Multi-Head Attention
* Medical image classification
* Data augmentation
* Class weighting
* Model evaluation

📁 **Assignment:** [Pneumonia Detection using CNN-Transformer](./Assignment-02-Pneumonia-Detection-CNN-Transformer/)
