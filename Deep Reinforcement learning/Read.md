# Deep Reinforcement Learning (DRL)

This folder contains coursework and assignments completed as part of the **Deep Reinforcement Learning** subject in my M.Tech program.

## Assignments

### 1. Dynamic Programming and Multi-Armed Bandits

Implementation of reinforcement learning concepts through Smart Supplier optimization and clinical trial treatment selection.

**Key concepts:**
- Dynamic Programming
- Value Iteration
- Multi-Armed Bandits
- Exploration vs. Exploitation
- Epsilon-Greedy
- Upper Confidence Bound (UCB)

📁 **Assignment:** [Dynamic Programming and Multi-Armed Bandits](./Assignment-01-DP-and-Multi-Armed-Bandits/)

---

### 2. Deep Reinforcement Learning

Implementation of deep reinforcement learning techniques across two applications: autonomous drone battery management and ICU/sepsis treatment optimization.

**Key concepts:**
- Deep Q-Network (DQN)
- Double DQN (DDQN)
- Experience Replay
- Epsilon-Greedy Exploration
- Actor-Critic
- Actor and Critic Networks
- Reward-based Policy Learning

📁 **Assignment:** [Deep Reinforcement Learning](./Assignment-02-Deep-RL/)
