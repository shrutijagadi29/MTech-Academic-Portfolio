# Machine Learning Operations (MLOps)

This folder contains assignments completed as part of the **Machine Learning Operations (MLOps)** coursework in my M.Tech program.

The coursework focuses on building reproducible and production-ready machine learning systems covering the complete lifecycle from model development to deployment and monitoring.

## Assignments

### 1. Heart Disease Prediction - End-to-End MLOps Pipeline

Development of a machine learning pipeline for predicting heart disease risk using the **Heart Disease UCI Dataset**.

**Key concepts:**
- Data preprocessing and EDA
- Feature engineering
- Machine learning classification
- Experiment tracking with MLflow
- Model packaging
- Automated testing
- CI/CD
- Docker containerization
- REST API deployment
- Kubernetes / Cloud deployment
- Monitoring and logging

📁 **Assignment:** [Heart Disease Prediction MLOps Pipeline](./Assignment-01-Heart-Disease-MLOps/)

---

### 2. Cats vs Dogs Classification - End-to-End MLOps Pipeline

Development and deployment of a **binary image classification system** for classifying Cats vs Dogs while implementing a complete MLOps workflow.

**Key concepts:**
- Image classification
- CNN model development
- Git-based code versioning
- DVC / Git-LFS data versioning
- Experiment tracking
- REST API development
- Docker image creation
- Continuous Integration (CI)
- Continuous Deployment (CD)
- Automated testing
- Container registry
- Smoke testing
- Model monitoring and logging

📁 **Assignment:** [Cats vs Dogs MLOps Pipeline](./Assignment-02-Cats-Dogs-MLOps/)
