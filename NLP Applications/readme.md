## Assignments

### 1. Spell Checker Application

**Key concepts:**
- Spell Checking
- Text Correction
- Multilingual NLP
- Flask Web Application
- Frontend and Backend Integration
- Knowledge Graph Applications

### 2. Statistical Machine Translation

Development of a **Parallel Corpus-Driven Statistical Machine Translation (SMT) System** using alignment and statistical translation techniques.

**Key concepts:**
- Statistical Machine Translation (SMT)
- Parallel Corpus
- Sentence Alignment
- Word Alignment
- IBM Model 1 / FastAlign
- Phrase Extraction
- Translation Probabilities

- Parallel Corpora in SMT
