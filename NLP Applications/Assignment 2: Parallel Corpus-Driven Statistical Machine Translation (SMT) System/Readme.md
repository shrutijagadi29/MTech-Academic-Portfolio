# Assignment 2 - Statistical Machine Translation

## Overview

This assignment focuses on building a **Parallel Corpus-Driven Statistical Machine Translation (SMT) System**.

The system uses a parallel corpus to learn translation relationships between two languages and generate translated sentences.

## Part 1 - SMT System

The Statistical Machine Translation pipeline includes:

- Parallel corpus processing
- Sentence alignment
- Word alignment
- Phrase extraction
- Translation using a Noisy Channel Model

## Word Alignment

Word alignment is performed using:

- IBM Model 1 or FastAlign
- Translation probability estimation
- Source-target word relationships

## Corpus Analysis

The implementation analyzes:

- Number of sentence pairs
- Vocabulary size
- Learned translation probabilities

## Data Impact Analysis

The assignment also studies how SMT performance is affected by:

- Increasing corpus size
- Removing noisy sentence pairs
- Domain mismatch

## Part 2 - Literature Survey

A literature survey is conducted on:

**The Role of Parallel Corpora in Statistical Machine Translation**
