# Assignment 1 - Spell Checker Application

## Overview

This assignment focuses on developing a web-based **Spell Checker Application** that identifies misspelled words in user-provided text and suggests appropriate corrections.

The assignment also explores multilingual spell checking and applications of Knowledge Graphs.

## Part A - Spell Checker Application

A web-based spell checker is developed with a user-friendly interface for entering and correcting text.

### Key Features

- Accepts text input from the user
- Identifies misspelled words
- Provides correction suggestions
- Displays the original and corrected text
- Displays results on the web page and terminal
- Integrates the frontend with a Python backend

## Web Application

The application uses:

- HTML and JavaScript for the frontend
- Flask for the Python backend
- A spell-checking library for detecting and correcting misspelled words

## Enhancement Plan

The assignment includes documentation describing how the spell checker can be enhanced to support **multiple languages**, along with real-time use cases.
