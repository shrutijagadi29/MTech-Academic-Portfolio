# Machine Learning (ML)

This folder contains coursework and assignments completed as part of the **Machine Learning** subject in my M.Tech program.

## Assignments

### 1. IMDB Sentiment Classification

Sentiment classification of IMDB movie reviews using machine learning and natural language processing techniques.

**Key concepts:**

* Text preprocessing
* TF-IDF feature extraction
* Logistic Regression
* Decision Tree
* Random Forest
* K-Nearest Neighbors (KNN)
* Model evaluation using Precision, Recall, F1-Score, and AUC-ROC
