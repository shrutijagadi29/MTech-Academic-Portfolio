# IMDB Sentiment Classification

## Overview

This project was completed as part of the **Machine Learning** coursework in my M.Tech program.

The objective is to perform **sentiment classification on IMDB movie reviews** and predict whether a given review expresses a **positive or negative sentiment**.

## Dataset

The project uses the **IMDB Reviews dataset**, containing movie reviews along with their corresponding sentiment labels.

**Target Classes:**

* Positive
* Negative

## Project Workflow

The project follows the following machine learning workflow:

1. Data loading and exploration
2. Data visualization
3. Text preprocessing and cleaning
4. Feature extraction using **TF-IDF**
5. Train-test data splitting
6. Model training
7. Model evaluation and comparison

## Machine Learning Models

The following classification algorithms were implemented and evaluated:

* Logistic Regression
* Decision Tree
* Random Forest
* K-Nearest Neighbors (KNN)

## Model Evaluation

The models were compared using classification performance metrics including:

* Precision
* Recall
* F1-Score
* AUC-ROC

The performance of the different classifiers was analyzed to identify the most suitable model for sentiment classification on the given dataset.
