# Advanced Deep Learning (ADL)

This folder contains assignments completed as part of the **Advanced Deep Learning** coursework in the M.Tech program.

## Assignments

### Assignment 1 – PCA and Autoencoders

This assignment explores dimensionality reduction and representation learning using:

- Principal Component Analysis (PCA)
- Logistic Regression
- Linear Autoencoders
- Convolutional Autoencoders
- MLP Autoencoders
- Latent Feature Extraction
- MNIST 7-Segment Classification
- ROC/AUC and Confusion Matrix Analysis

**Datasets:** CIFAR-10 and MNIST
